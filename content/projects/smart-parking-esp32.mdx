## Overview

A smart parking management system designed, built, and tested end-to-end using the ESP32 microcontroller. The system tracks parking bay occupancy in real-time and exposes the data over IoT protocols for remote monitoring — with a fully hand-built physical prototype to validate the design.

## Problem

Manual parking management is inefficient and doesn't scale. The goal was to design an automated system that could detect occupancy, process that data on-device, and publish it for remote consumption — all on low-cost, readily available hardware.

## Implementation

- **Microcontroller**: ESP32 running C written with Arduin IDE.
- **Occupancy sensing**: Ultrasonic (HC-SR04) sensors per parking bay, debounced in firmware
- **Entry/exit control**: Servo motors acting as automated barriers at entry and exit points
- **Indicators**: Red/green LEDs per bay showing occupancy status at a glance
- **IoT communication**: MQTT protocol for lightweight real-time data publishing
- **Alert system**: Buzzer for entry/exit events
- **Prototype**: Fully hand-built cardboard model with painted road markings, servo barriers, breadboard electronics, and a working wiring harness

## Outcome

The prototype demonstrated accurate real-time occupancy tracking across all three bays, with servo barriers responding correctly to vehicle detection. The architecture is designed to scale to multi-level facilities with a central MQTT broker aggregating data from multiple ESP32 nodes.
